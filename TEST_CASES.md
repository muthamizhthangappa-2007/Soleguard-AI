SoleGuard AI — Test Cases

1. Introduction

This document describes the test cases for the SoleGuard AI web prototype, designed to demonstrate smart foot-pressure monitoring for diabetic foot-care awareness.

Project: SoleGuard AI
Testing Type: Manual functional and interface testing
Platform: Web browser
Status: Test cases prepared; execution results must be recorded after testing.

Important: The prototype uses simulated pressure readings. These tests assess software behavior only, not medical accuracy or effectiveness.

4. Acceptance Criteria

The prototype may be considered ready for a demonstration when:

- The website opens successfully.
- Implemented interface components display correctly.
- Demonstration alerts behave according to the programmed rules.
- The interface works on the intended screen sizes.
- No critical errors prevent the demonstration.
- Simulated readings and medical limitations are clearly disclosed.

5. Known Limitations

- No real pressure-sensor testing is covered unless hardware is separately integrated.
- Simulated values cannot verify a person's actual foot-pressure distribution.
- Threshold alerts are not clinically validated.
- These tests do not establish that the system can diagnose, predict, or prevent diabetic foot ulcers.

6. Conclusion

These test cases provide a basic plan for checking the functionality and usability of the SoleGuard AI prototype. Actual results should be recorded after running the tests. Further engineering and clinical validation would be required before evaluating the system for real-world healthcare use.
